# Codebase map

Implementation notes moved from `AGENTS.md`. Consult the source and regression tests for current behavior; these notes are not a feature-completeness contract.

- `simd.zig` — SIMD utilities: byte scans (`skipUntil`, `skipToAny`, `scanText`: `skipToAny` plus the printable-ASCII prefix in the same pass) and the UTF-8 run decoder `decodeUtf8Run(mode, src, dst)`: validates and decodes 64-byte blocks of 2-/3-byte sequences (plus 0x20..0x7E in `.printable` mode) with vectors (back-to-back 3-byte or 2-byte runs through one fixed shuffle, mixed ones through a lead-mask walk), scalar `decodeUtf8Step` for 4-byte, invalid input and tails. Semantics equal `decodeUtf8RunScalar` (invalid sequences skipped by their lead's length, stray bytes one at a time, a truncated tail ends the run and consumes the slice); `.printable` also ends a run before a block that starts with 32 printable ASCII bytes. Differential tests cover random bytes and every truncation/flip
- `debug.zig` — Debug-mode log + visual overlay (OSC 556 / CSI ? 556; ignored in Release). HUD: cursor, flags, dirty count `D`, last OSC `o`, `SYNC`/`NTF`
- `circbuffer.zig` — mirrored 1 MiB ring; unconsumed bytes are never overwritten. `readSource`/`readPTY` wait on EAGAIN (never poll 0 ms) and call `drain(sink, true)` above 75% occupancy; normal frame consumption uses `drain(sink, false)`. The only skip control is this pressure guard. No ratio heuristic, persistent skip-policy state, or partial-run queue. `Sink.feed` returns a consumed-run count. In pressure mode the consumer uses `preparser.isSpanObsolete(index)` and pauses before the live suffix; its raw bytes stay in the ring as lookahead. A proven-obsolete prefix can be consumed and its frontier reframed against the next bounded metadata window. Without such a proof, consumption releases at least a quarter-ring before pausing, avoiding threshold thrashing on small PTY reads. Normal frame drains flush the retained suffix. `exact` disables omission for reference parses, and a false pressure guard disables it for normal frame consumption. Metadata limits/OOM consume bounded prefixes and retry without dropping runs. A future unterminated string is opened only after all preceding runs are consumed; completed stream bytes advance the ring tail before a partial feed. Unterminated OSC/DCS/APC move to the stream buffer (grows geometrically to `max_stream`, 320 MiB, discarded through the terminator above it, compacted with `@memmove` after the feed, freed above 1 MiB when idle). Only the bytes already in the ring (at most one ring-full) are copied there (`openStream`); while the string is open and the ring is empty, `readSource` reads straight into the stream's spare capacity (`directDest`/`streamRead`: reads no larger than the string so far, at least 4 KiB and at most the ring, so the copy of bytes after the terminator back into the ring stays small), searching only the new bytes for the terminator (an ESC at the end of one read pairs with `\` at the start of the next) and putting what follows it back into the ring; the finished string is marked `open.closed` (`pending()` is true) and the next drain emits it as a run with `flags.stream`, ahead of the ring bytes. Callers that only push into the ring (tests, `drainAll`) take the ring path (`continueStream`) with identical runs. `Sink.feed` also receives the `*CircBuffer`; `takeStream(allocator, off, len)` hands the whole stream buffer to the consumer of the run that ends it (≥ half a ring, no string open behind it, same allocator; the stream restarts empty); incomplete trailing CSI/ESC/UTF-8 (≤ 4 KiB) is held. `exact` feeds everything (reference parses). Metadata storage is capped independently of ring size.
- `preparser.zig` — owns `Run`, `Role`, `View`, reusable span arrays and cached CSI heads/parameters; no ring/VT dependency or owned input bytes. Hard workset limits are 4096 runs, 2048 CSI heads, 8192 parameters and 4096 subparameters (160 KiB dynamic metadata total). Arrays grow precisely up to those limits and are reused; a full workset returns a retryable prefix rather than growing with the ring. CSI-cache allocation failure still falls back to raw parsing. `prepare(bytes, offset, view, exact, initial)` only frames a bounded prefix, caches its initial view, and resets the obsolescence cache; it performs no validation/marking pass and drops no spans. `isSpanObsolete(index)` is the single consumption-time predicate: exact mode and SGR/state/query/image spans return false; text and LF cell work may be omitted only with a visibility proof. The first eligible query lazily caches per-screen cutoffs, using a no-clear/insufficient-LF gate and stopping once all relevant screens have cutoffs; subsequent queries are O(1). Cutoffs require qualifying clears (ED 2, home+ED 0 with origin off, RIS, entering 1049) or `2*rows-1` full-region scrolling LFs without invalidating motion or source-reading rectangle copies; switches/restores reset counts, and XTRESTORE disables pruning conservatively. No text quotas, pen-reader arrays, SGR elision, or compaction passes. All SGRs, queries, state changes and graphics remain ordered. `flags.plain` records a printable-ASCII prefix (saturated at 511). `csiAt` shares each scanner-parsed CSI with the VT in run order; on cache OOM the VT reparses raw bytes. Ghost text still advances cursor/wrap/grapheme state; obsolete LF cell scrolling retains its existing fast path.
- `vt.zig` — minimal-state emulator; `feedFrom(runs, stream)` / `feedRuns` route text/C0/ESC/CSI/OSC/DCS/kitty; consumption calls `owner.preparser.isSpanObsolete(run_index)` using a lazy, cached visibility proof; `feedOwned` returns how many runs were consumed and may pause before live cell work during pressure, without touching that span's cursor/grapheme state; CSIs come pre-parsed from the drain (`owner.preparser.csiAt`, in run order; `feedFrom` without an owner parses), SGR goes straight to `csi.sgr`, everything else through `apply`; `.text` runs start with their scanner-found printable prefix (`feedTextFrom`: printed without a second scan, the byte after it known not printable) and are split while feeding (`feedText`: 0x20..0x7E via bulk `printPlain`, C0/DEL via C0, from the first non-ASCII byte via `printUtf8`: decodes 256 codepoints at a time with `SIMD.decodeUtf8Run`, then a tight print loop (one `Grapheme.props` lookup per code point for width and break class) with only the column in a local (each 256-codepoint chunk ends synced: REP's character and the open cluster are written back before any call and at chunk end; the last column and pending wraps go through `printCodepoint`, so the loop never touches `wrap_pending`) and ghost and 2027 hoisted out (comptime); with the ASCII charset the run also takes printable ASCII and ends at C0/DEL, under DEC special graphics it ends at any ASCII byte; wraps/margins/insert/single shifts fall back to `printCodepoint`; stray high bytes are ignored: raw 8-bit C1 controls are not recognized in UTF-8); the pen stays raw colors/attrs in the grid and `penId()` interns `penStyle()` per print call (a cache compare unless the pen changed), `eraseCell()` interns the erase style; `styleOf(cell)` resolves; `rep` (CSI b) repeats `last_cp`, the last code point that started a cell (a cluster's base, as Ghostty's `previous_char`); of plain ASCII it goes through `printPlain`. Grapheme clusters: `Join` tracks the cell the last printed character started (grid, row, col, cursor after it, width, length, base code point; UAX #29 state and last props only once something joined) while nothing but text and SGR comes after it (every C0 in `C0.dispatch`, every non-SGR escape in `feedOwned`, scrolls, resize, alt switch and reset end it; `joinable()` also requires the cursor and `wrap_pending` unchanged). Mode 2027 off: zero-width code points (`props.width == 0`: marks, ZWJ/ZWNJ, VS, other default ignorables, Hangul V/T) join that cell (`joinMarks`: a run of them interned once; VS15/16 only after an Extended_Pictographic base), with no open cluster they are dropped; everything else prints at its own width as before. Mode 2027 on: a code point joins when `Grapheme.breaks` says no boundary (`joinShaped`), with Ghostty's width effects (`Grapheme.effect`: VS16/VS15 after a variation base widen/narrow the cell, ignored after anything else; a joined code point with width of its own, e.g. a spacing mark, Prepend + base or ZWJ + emoji, makes it wide); a narrow cluster at the last column that turns wide moves to the next line (blank left behind, row soft-wrapped) or, without autowrap, drops the code point; a zero-width code point that breaks is dropped. Clusters stop growing at `Clusters.max_len` (32): later joining code points are dropped (the break state still advances, so the boundary stays right). Ghost text tracks `Join` the same way without touching cells. The fast loops leave the cluster logic only for zero-width code points (2027 off) or code points that `Grapheme.alwaysBreaks` cannot rule out (2027 on), and `printPlain` (ASCII) only checks for a Prepend before its first byte (2027 on); `prepareImages` decodes images in view before a render (row-at-a-time fill; wrap, insert mode and DEC charsets fall back to `printCodepoint`). Palette/default-color changes (`applyScheme`, OSC 10/11/110/111, XTPOPCOLORS) recolor the style table entries, not cells; `dumpAlloc`/`dumpCellsAlloc` print resolved styles and clusters as all their code points (`dumpCellsAlloc`: `U+0065+0301`; unchanged format otherwise, the `tests/vt` fixtures are byte-identical and checked by the vt test "vt fixtures stay byte-identical")
- `grid.zig` — cell buffer (8-byte `Cell`: `codepoint: u21`, `style: u32` id; a codepoint field at or above `cluster_base` (0x110000, past Unicode, so compares with real code points never match) is a grapheme cluster `cluster_base + id` in `Styles.clusters` (`Clusters`: code points back to back, per-id span with the content hash, hash map deduplicating by content; `internCluster(cps)` returns the code point itself for one; `text(cell, &one)`/`base(cell)` resolve; `compactClusters` runs when `limit` (4096, doubling when more than half survive, at most 0xF0000 ids) is reached: marks ids in both grids' whole rings, renumbers survivors in order, rewrites cells and bumps the shared `gen`, so the renderer's snapshot invalidation covers clusters too; out of ids/memory a cell keeps the base code point). Single code points never touch the table; `fillCells` is the vectorized `@memset` on u64), interned `Style` (fg, bg as resolved RGB exactly as the pen held them, underline color, `Attrs`) in `Styles` (heap, shared by both grids; id 0 is `Style{}`'s slot; interns check the last one, then a 32-entry direct-mapped memo, then the hash map (memo cleared with `gen`); when `list` reaches `limit` (65536) `compact` marks ids in both grids' whole ring including scrollback and unused rows plus the row `tail`s, renumbers survivors in order and rewrites cells; `limit` doubles when more than half survive, so ids are never reused while referenced; `recolor` edits entries in place; both bump `gen`. Never keep an id across a call that may intern a new style — fetch it again), cursor, last-column flag (`wrap_pending`), scroll region, insert/delete; primary reflow on column resize (soft-wrap flags, styled blanks, and actual-wrap cursor mapping); height-only primary shrink keeps cursor content by moving top rows into history, with bounded graphics anchors remapped alongside cells and pinned against blank-row trimming. Grids register their cell/tail buffers as `Styles.roots` (`register` after every reallocation). Each ring row tracks `extent`/`tail`: cells past `extent` equal the blank it was last cleared with, so `clearRange` of a whole row only fills `[0, extent)` (every scrolling LF recycles a row). Print paths use `cellPtr` + `noteWrite`; mutable `getCell`/`rowSlice`, insert/delete and resize mark rows fully written (an untracked writer only costs speed). `lineIndex` replaces `% cap`
- `c0.zig` — C0 dispatch (every control but a direct-caller space ends the open grapheme cluster; BEL ignored; HT advances to the next tab stop without changing cells; BS reverse-wrap; LF/VT/FF are index only so terminfo `cud1` stays in column; NEL is CR+LF; cooked NL becomes CR NL via PTY `OPOST|ONLCR`; LCF delayed DECAWM wrap)
- `esc.zig` — ESC parse + charset G0–G3 / RIS / HTS / DECALN / SS2/SS3
- `csiparse.zig` — the CSI parser (no VT dependency): `scan` finds a CSI's end and parses it in one pass (`;` params as 8-byte `Param {value, sub_off, sub_len}`, `:` subparams in a shared `subs` slice, at most 8 per param and 128 per sequence, packed privates; values wrap; any byte other than digits, `;:`, intermediates and privates makes `final` 0), `parse` for a complete sequence
- `csi.zig` — apply of a parsed CSI (`CsiSeq.of` a scanner result, or `parse` into `Bufs`) (foot ctlseqs: SGR, CUP, DECSET, DECRQM, rectangular, kitty kbd, window ops, color stack, XTSMGRAPHICS); debug-only CSI `? 556` overlay
- `osc.zig` — OSC 0/2 title, 4/10–12/104/110–112 colors, OSC 8 hyperlinks, 7 cwd, 9/99/777 notify (OSC 9;4 ConEmu progress and 9;9 cwd are not notify; OSC 777 only `notify;`; kitty OSC 99 `d=2` closes), 11 alpha, 17/19 selection, 22 cursor, 52 clipboard, 66 text, 133 marks, 176 app-id, debug-only 556 overlay (`all`/`off`/`grid,wrap,lcf,cursor,dirty,region,wide,hud`)
- `dcs.zig` — DCS DECRQSS (DECSTBM/SGR/DECSCUSR) + iTerm sync + XTGETTCAP + sixel (`sixel.zig`)
- `draw.zig` — CPU framebuffer; line-dirty fill + SIMD glyph blit; color-emoji RGBA blit; each cell's colors/attrs come from `screen.styles.of(cell)` (bg spans skip the lookup while the style id and selection state repeat); cell-span dirty when a prev snapshot exists (style ids compare only within one `Styles.gen`: a compaction or recolor drops the snapshot and repaints everything); scroll reuse shifts pixels by the best-matching N-row offset (searched only when most lines are dirty; unmatched rows repaint); rows covered by kitty/sixel placements now or last frame repaint (not the whole screen), with clipped placement scaling; DECSCNM reverse; styled/colored underlines; C0 cells are not rasterized; cluster cells take `drawCluster` (off the single-codepoint path, which still inlines `blitGlyph`): the base glyph (Hangul L V (T) and LV + T composed to the syllable), then, unless the base is a color emoji (no shaping: emoji ZWJ/flag/modifier sequences show their first emoji), its marks: a mark drawn left of its origin goes after the base advance, one drawn right of it on the cell, spacing marks advance the pen; joiners, selectors, tags and composed jamo draw nothing; Debug overlay (grid, wrap, LCF, dirty, region, wide, HUD)
- `fontsource.zig` — shared platform font discovery: fontconfig on Linux, native font loading elsewhere; primary substitution is allowed, requested fallback families must match. Fontconfig collection indices are retained through primary/lazy loading, rasterization, and font identity. No hardcoded primary/emergency font paths. Main/benchmark eagerly load only the configured primary (system `monospace` when unset); styled faces and ordered coverage families are registered as lazy candidates. `type.Context` owns deferred names and loaded fallback bytes, deduplicates font bodies, caches failed attempts, and clears them on reload/deinit. Built-in emoji-only candidates are skipped for non-emoji misses; configured fallback order takes precedence.
- `type.zig` — TrueType rasterizer, coverage + RGBA atlas, bounded glyph cache (true LRU: hits on the glyph and render paths refresh recency; codepoint+style -> face/glyph resolve memo, 4096 direct-mapped, cleared on font changes); bold/italic faces; CBDT/CBLC color emoji (`type/cbdt.zig`); `type/eastasian.zig` cell width; `type/grapheme.zig` — `props(cp)` (one two-stage lookup in the generated `type/grapheme_table.zig`, stage1 covering all of u21: width 0/1/2 = `EastAsian.cellWidth` or 0 for joiners, a 20-value break `Class` (GCB plus InCB for GB9c), VS15/16 base), `State`/`breaks` (UAX #29 Unicode 18 incl. GB9c as Unicode 18 has it: Linker [Extend|Linker]* × Consonant), `alwaysBreaks` (comptime 32x32 table: no state can join), `effect` (Ghostty's cluster width effects); tests check GraphemeBreakTest.txt and that every nonzero width equals `cellWidth`. Regenerate with `python3 scripts/gen_grapheme.py zig-pkg/uucode-0.2.0-*/ucd` (stdlib only; reads GraphemeBreakProperty, GraphemeBreakTest (emitted as test vectors), DerivedCoreProperties (InCB, Default_Ignorable), DerivedGeneralCategory, emoji-data, emoji-variation-sequences, and the ranges in `eastasian.zig`)
- `scheme.zig` — TOML subset (colors, font, pad; hz/whitelist are legacy parsed settings with no runtime effect; cadence uses the Hyprland monitor rate or 60 Hz). Supported settings use bare table/key names and single-line strings, with basic escapes decoded; unrelated values, quoted names, array tables, multiline strings and nested collections are skipped without full TOML validation (collections are bounded to 64 levels). Integer settings parse directly into checked u32 values; finite font sizes accept exponents and digit separators. Loads Omarchy current theme; font size from Alacritty, then 9 pt only if the current theme's colors.toml is a regular file, otherwise 8 pt; family from fontconfig `monospace` (`omarchy font`). `[font].fallbacks` is an ordered array of up to 16 installed family names (128 bytes each), applied before built-ins; overlays replace the array, `[]` clears custom entries only
- SIGUSR1/SIGUSR2 or Omarchy theme/font file change reloads colors and font in `main.zig` (`fc-match` needs process environ so HOME/fonts.conf apply); custom and built-in Noto family resolution verifies the matched family so missing names cannot silently load an unrelated substitute; primary patterns keep fontconfig substitution. DejaVu/Noto coverage families are discovered lazily by name; no font files are loaded for them until needed. Blank space glyphs count as primary coverage even without outlines, preventing ASCII warmup from loading fallbacks.
- `select.zig` — cell-stream selection over `vt.VtState` (drag, double-click word, triple-click line)
- `key.zig` — PTY key encoding: Shift+Tab CSI Z, modified arrows CSI 1;mod A, xterm modifyOtherKeys `CSI 27;mod;key~`, kitty keyboard protocol CSI u when flags are pushed; Delete is CSI 3~ (not DEL 0x7F, which the tty treats as backspace)
- `kitty.zig` — kitty graphics (APC G: stream + file/temp, `a=q` OK replies for icat); multipart encoded data capped at 320 MiB; file reads are nonblocking regular-file only, and file reads reopen pinned regular files through /proc/self/fd; temporary unlink is restricted to protocol-marked direct children of /tmp, /var/tmp, /dev/shm, or an absolute TMPDIR; sixel bitmaps placed through the same store. Images keep their payload (`Pending`: base64, file bytes, or a private-palette sixel body; `owned` is the whole allocation when `data` lies inside a handed-over stream buffer, freed by `Pending.free`). `VtState.feedOwned` gives `Store.feedDonor` a `Donor` for stream runs: a complete single-APC direct transmission (not `m=1` chunked) takes the ring's stream buffer (`takeStream`, shrunk with `remap` when slack is large) instead of copying the payload into `chunks`, so the base64 is written once, by read(2); chunked transfers keep the single copy into `chunks` and `chunks` → `pending` stays a move and decode in `decodeVisible` only when a placement is in view; limits are 320 MiB transfers, 10000 px per image, 64 images and a 320 MiB logical cache quota (larger of encoded payload/decoded RGBA, held stable across lazy decode; decode scratch/allocation slack are extra); a finished transfer moves out of `chunks` (no copy); size comes from `s`/`v`, the PNG IHDR, or `Sixel.measure` (other encoded formats and shared-palette sixels decode immediately). ED 2 (and ED 0 from home) drop the screen's placements; anonymous/sixel data is freed after its last placement expires; named Kitty data remains cached for later a=p after placement deletion, screen clear or history expiry, until explicit uppercase data deletion or quota eviction. Eviction prefers unplaced cache entries, and unknown delete selectors do not clear the store. Retransmitting an id drops its old placements. A failed lazy decode removes the image and its placements, and `draw.zig` skips images whose pixels are short. Placements are anchored to absolute lines (`Grid.base`, +1 per line pushed into history; oldest kept line is `base - (used - rows)`): history scrolls are O(1) (`expire` scans only once the oldest line reaches `min_end`), partial-region and alt-screen scrolls shift only placements overlapping the region (one partly above its top keeps moving until fully out), column-change reflow remaps anchors (including blank cells/wide-glyph padding) and preserves the scrolled viewport rather than dropping history images. ED 3 expires only placements fully outside the retained view. Natural/scaled geometry is shared by rendering, cursor advancement and expiry; C=1 suppresses cursor movement. Images draw in the history view
- `sixel.zig` — DCS q decoder (palette, repeats, raster attrs) → RGBA; `measure` is the same walk without painting (size only)
- `platform/` — Peak backend. `peak.zig` declares calls to vendored `vendor/godstack/Peak`; `build.zig` compiles its `peak.c`. Window + backbuffer present, focus/expose, WM_CLASS / xdg app-id (`--class` / OSC 176), opacity (X11 `_NET_WM_WINDOW_OPACITY`; Wayland `wp_alpha_modifier_v1`, else buffer alpha), clipboard CLIPBOARD plus primary (`zwp_primary_selection_v1` on Wayland). Wayland backbuffer is logical size × fractional scale (`wp_fractional_scale_v1` + `wp_viewport`; integer `wl_output` scale if those are absent) and pointer coordinates are in that buffer. Each commit sets `xdg_surface.set_window_geometry` and `wl_surface.set_input_region` to the logical size so a scaled buffer cannot take clicks outside the tile. The configure ack commits that clip immediately, without waiting for the next present, and pointer events outside the logical window are dropped (strict half-open bounds, rechecked for clicks/wheel after resize; extra mouse buttons are ignored rather than mapped to left-click). Temporary input regions are destroyed on the server after use. `peak_window_present_rect(y, h)` copies only those rows to the Wayland shm and sends `wl_surface.damage_buffer` (full damage when the shm is stale, opacity changed, or wl_surface < 4); X11 puts only those rows. Pointer events follow the entered surface; leave releases held buttons instead of extending the selection. Wheel is `wl_pointer` `axis_value120` / discrete, one click per detent. Cursor shape (OSC 22) is `wp_cursor_shape_v1` (text, hand, wait, crosshair, not-allowed, help) and hide uses `wl_pointer.set_cursor`. Motion is always delivered. PTY is `peak_pty_spawn` (`$SHELL` or `-e`); slave keeps `OPOST|ONLCR`; child env `TERM=xterm-256color`, `COLORTERM=truecolor`, `TERM_PROGRAM=velocitty`, `KITTY_WINDOW_ID`, `COLUMNS`, `LINES` is set around the spawn and restored in the parent; `TIOCSWINSZ` + `SIGWINCH` to the slave fg pgroup. Wayland compose is Peak's xkbcommon path; X11 text is `XLookupString` (no Multi_key compose). Keyboard text is retained per event; PTY writes queue on backpressure and flush in order without blocking. A key or paste while scrolled calls `viewBottom`
- `main.zig` — release builds allocate with `std.heap.c_allocator` (malloc reuses freed large blocks; `DebugAllocator` mapped and faulted fresh pages per image), Debug keeps `DebugAllocator` for leak checks; window + PTY + fonts (regular/bold/italic via fc-match, Noto Color Emoji fallback); `circbuffer` → `vt` → `draw` → Peak present (gated by `need_draw`; `Presenter` copies only the frame's damaged rows and calls `presentRect`, full blit + present when the window buffer, layout or pad color changed or after expose/resize); each tick `readSource` with `term.sink()` (EOF or EAGAIN+1/hz) pumps Peak during EAGAIN waits (successful reads are not deadline-bounded; full rings drain into the VT mid-read), then `drain` and `need_draw` from `circbuffer.fed`; `prepareImages` before `renderSel`; DECSET 2026 / iTerm DCS `=1s` defers present until sync ends (bounded by `hz` loop iterations, approximately 1s at intended cadence); mouse reports (1000/1002/1003 + SGR/urxvt/pixels) for buttons/motion/wheel, else alt-screen arrows or primary history view; Shift+Tab sends CSI Z (CSI 9;2u with kitty kbd); modified keys and kitty CSI u via `key.zig`; left-drag selects (Shift+drag when mouse reporting is on); double-click word / triple-click line (click chains and held/drag state reset on focus changes); mouse-up copies PRIMARY; Ctrl+Shift+C copies CLIPBOARD; Ctrl+Shift+V / Shift+Insert paste CLIPBOARD, middle-click pastes PRIMARY (bracketed if DECSET 2004); focus CSI I/O (1004) and visibility 2033; theme-change 2031 on palette reload (watchStamp throttled); inner pad from `[general] pad` (default 14), scaled by Wayland output scale; font/pad/cells use CSS 96 DPI × Hyprland/`GDK_SCALE` multiplier (not X11 mm-DPI) and re-apply on focus/resize only when scale/grid actually change; resize updates the grid, PTY winsize (SIGWINCH), real window pixel geometry (CSI 14/15/16), and flushes VT replies (in-band 2048 if enabled); CLI `-e`/`--` command, `--class=`, `--title=`, `--working-directory=` (xdg-terminal-exec)
