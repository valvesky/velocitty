# Testing reference

Commands are run from the repository root. Test counts and results must be measured for the current change, not inferred from this guide.

## Firehose regression tests
- `zig test src/preparser.zig` checks hard metadata limits and allocation-free reuse after warmup, run offsets, incomplete tails, stream ordering, CSI-cache allocation failure, lazy cached span obsolescence, exact-mode override, per-screen visibility proof, and pressure without visible-text loss.
- `zig test src/circbuffer.zig src/stb_image.c -Ilib -lc -target x86_64-linux-musl` checks framing without eager validation, incomplete UTF-8/escapes and stream strings, pressure activation with a final normal batch, retained live lookahead across reads and metadata windows, quarter-ring hysteresis for unprovable text, deferred stream opening and wrapped stream completion during partial feeds, metadata-allocation failure without dropped runs, all SGRs applied in order, and the drain: dead text fed as ghost (2*rows-1 LFs), every escape fed in a dead region, which clears are barriers (not ED 3, not home+ED 0 under DECOM, only 1049 entered from the primary screen), stream larger than the ring and over the cap, held CSI/UTF-8, dead kitty transfers fed in full. Output ingestion omits invisible paint/history only through this tagging; it is separate from keyboard/paste delivery to the PTY.
- Differential contract: `zig test src/firehose_test.zig src/stb_image.c -Ilib -lc -target x86_64-linux-musl` feeds identical chunks to an `exact` ring/VT and a draining one (rings of 1024/4096 bytes and 1 MiB; direct writes and `readSource` with a fake source) and compares visible state after normal frame flushes: cells (codepoint + resolved style; style ids differ with interning order) and soft-wrap flags of both screens, active screen, cursor/`wrap_pending`, pen, saved cursor, scroll region, flags/modes/charsets, saved modes, tab stops, palette, title (+stack), cwd/notify/clipboard, sixel state, kitty transfer state, every `reply` byte, and on-screen kitty/sixel placements (decoded pixels after `prepareImages`). History rows and `last_cp` are not compared. Contains a multi-ring 1 MiB mixed grapheme/SGR/query/mode/chunked-image regression across bounded metadata worksets, repeated obsolete-span consumption cases and SGR-heavy large reads with visible ASCII/UTF-8, named regression cases, split-at-every-byte sweeps and a seeded fuzz with a shrinker (prints seed, shrunk bytes and a tally of the first differing item). Also reached from `src/port_test.zig` (`zig build test`).

## Peak input regression tests
- `zig build test` runs the headless X11 callback regressions in `tests/peak_x11.c`; `zig build check` compiles them for Linux.
- Velocitty builds Peak with `PEAK_NO_GAMEPAD`: no direct `/dev/input/js*` polling. Gaming mice can expose joystick interfaces; converting their global button events into pointer events caused clicks at (0,0) in every terminal, bypassing compositor routing.
- Headless joystick-disabled regression: `cc -Ivendor/godstack/Peak tests/peak_no_gamepad.c -o /tmp/velocitty-peak-no-gamepad -ldl -lpthread -lm && /tmp/velocitty-peak-no-gamepad`.
- Headless Wayland hit-region, resize/click, extra-button, wheel, and leave tests: `cc -Ivendor/godstack/Peak tests/peak_pointer.c -o /tmp/velocitty-peak-pointer -ldl -lpthread -lm && /tmp/velocitty-peak-pointer`.

- Headless keyboard callback and wrapper regression: `zig test tests/peak_keyboard.c --dep platform -Mroot=tests/peak_keyboard.zig -Mplatform=src/platform/platform.zig -lc -ldl -lpthread -lm`. Wayland special-key identities use compositor xkb keysyms (not physical evdev codes), and repeat eligibility uses the keymap. Includes a real libxkbcommon `caps:swapescape` regression for press/release, modified Escape, and repeat (skips if libxkbcommon is unavailable).
- Headless Wayland partial-present regression: `cc -Ivendor/godstack/Peak tests/peak_present.c -o /tmp/velocitty-peak-present -ldl -lpthread -lm && /tmp/velocitty-peak-present`.
- PTY backpressure and ordering regression: `zig test tests/pty_queue.c --dep platform -Mroot=tests/pty_queue.zig -Mplatform=src/platform/platform.zig -lc -ldl -lpthread -lutil -lm`.

## Main-loop regressions
- Inline `src/main.zig` tests cover paste control filtering and allocation failure, kitty all-keys Unicode text, no-button motion and urxvt mouse codes, resize allocation-error propagation, and Linux notification-child reaping. Run them with the direct inline command below or `zig build test`.

## Rendering tests
- Release-review regressions cover height-only shrink/history preservation, wide-glyph active/saved cursor mapping, styled blanks during reflow, reverse-mode invalidation, and shifted selection repainting. Font tests include portable synthetic collection members and an installed CJK collection smoke test (skipped if unavailable); both primary binding and lazy dedup retain the selected member. Graphics tests cover allocation-failure cleanup, clamped sixel RGB values, and collision-free anonymous IDs through wraparound.
- Config checks: `zig test src/scheme.zig -lc -target x86_64-linux-musl` (integer precision/overflow, ignored TOML values and array tables, escaped strings, actual theme-file font defaults, fallback array order, ownership, overlays, empty reset, malformed input and limits). `src/main.zig` also tests rejection of unrelated fontconfig substitutions and lazy fallback order/deduplication, one loaded face after primary ASCII warmup, cached failed loads, on-demand styled faces, reload cleanup, and symbol/braille coverage. The loading smoke test explicitly skips if fontconfig or the two Noto Symbols families are unavailable.
- Direct current inline check: `zig test src/main.zig src/type/stb_truetype.c src/stb_image.c -Ilib -lc -target x86_64-linux-musl`. The musl target avoids host GNU CRT `.sframe` linker incompatibility.
- `zig build test` runs `src/port_test.zig` (inline tests + portable Peak PTY) and `tests/peak_native.c`; `zig build check` compiles them without running; `python3 tests/package_test.py` checks package layouts. Inline `src/` tests and standalone Peak C checks are separate. Target image checks: `zig test src/draw.zig src/type/stb_truetype.c src/stb_image.c -Ilib -lc -target x86_64-linux-musl --test-filter image`. Regressions cover repeated reflow, history images and a scrolled viewport, blank-cell/wide-glyph anchors, resize before lazy decode, redraw/font-metric changes, and cached a=p after ED 2/lowercase deletion. Store tests cover natural cursor geometry, complete image-height expiry, cache quota/eviction and decode-independent accounting, reference-safe uppercase deletion, point deletion and cancellation of partial uploads. VT tests cover cursor wrap reset and sixel scrolling. Renderer regressions in `src/draw.zig` compare incremental and full frames across scrolling, image movement/deletion, style compaction, and recoloring.
- Cell dumps: `VtState.dumpAlloc` / `dumpCellsAlloc`. `tests/fixtures/unicode.txt` is a manual Unicode rendering sample, not an automated test.
