# Release
- `zig build release` builds ReleaseFast for every target whose SDK is available (`-Drelease-os=linux|windows|macos` restricts it). Linux gnu (glibc 2.28 floor) and dynamically linked musl, x86_64 and aarch64, link libc (and libdl/libpthread/libutil on gnu); Peak compiles against host X11 and Wayland headers (`-idirafter /usr/include`) and dlopens Wayland, X11, Pulse, and xkbcommon at runtime. Windows x86_64-gnu cross-builds from Linux (manifest + `assets/velocitty.rc` icon). macOS needs the native SDK or `-Dmacos-sdk=`; Peak is compiled with `.language = .objective_c` (a `-x objective-c` cflag is ignored because Zig puts cflags after the file).
- `zig build package` runs `scripts/package.py`: Linux `packages/velocitty-<version>-<triple>.tar.gz` (binary, desktop, icon, manpage, install/uninstall Makefile from `scripts/linux-package.mk`); Windows portable ZIP plus Inno Setup installer from `scripts/windows.iss` (ZIP only when not on Windows); macOS universal `Velocitty.app` (ad-hoc signed) in a DMG, built on macOS.
- `.github/workflows/release.yml` builds, tests, packages and smoke-launches on Linux (gnu + Alpine musl under Xvfb), Windows (silent install → `tests/desktop_smoke.py` → uninstall) and macOS (mount DMG, `lipo -verify_arch`, launch) for `main`, `release/**`, PRs and `v*` tags. `sign` and `publish` run only on `release/**` pushes or `v*` tags. When `SIGNPATH_API_TOKEN` is set, `sign` Authenticode-signs `velocitty.exe`, rebuilds the portable zip and Inno Setup installer from that binary, then signs the installer (`scripts/windows_sign.py`, artifact layout in `.signpath/artifact-configuration.xml`). `scripts/publish_release.py` uploads that signed Windows pair instead of the unsigned packages, plus the unsigned Linux and macOS packages and SHA256SUMS. Without the token, the Windows packages stay unsigned and the release still publishes. Release text is `RELEASE_NOTES.md`.
- Branding: `scripts/branding.py` regenerates `assets/icon.png`, `assets/icon.ico`, `assets/icon.icns` from the canonical `assets/icon.svg`, and the README wordmark/GIF via `ttfx` (`--icon-only` skips the wordmark).
- Windows ConPTY children get `STARTF_USESTDHANDLES` with invalid std handles; otherwise a child of a redirected parent writes to the parent's pipes instead of the pseudoconsole. Windows argv is quoted only when needed (cmd.exe ignores quoted switches like `"/c"`).

## Install
- `zig build` / `zig build install` is Zig's prefix install (default `zig-out/`: binary, `velocitty.desktop`, icon, manpage).
- `zig build install-usr` builds ReleaseFast for the host and installs `/usr/bin/velocitty`, `/usr/share/applications/velocitty.desktop`, the hicolor icon, and `/usr/share/man/man1/velocitty.1` so it appears in the Omarchy app menu. Uses `sudo` when stdin is a TTY, otherwise `pkexec`.
